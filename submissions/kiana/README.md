# Customer Data Cleaning and Analysis

## Overview

This project focuses on cleaning, validating, transforming, and analyzing a customer dataset using Python.

The project covers data quality assessment, missing value handling, duplicate detection, logical consistency checks, outlier detection, feature engineering, exploratory data analysis, and business insights.

## Objectives

- Identify and handle missing values
- Detect duplicate records
- Validate data types and logical consistency
- Detect potential outliers
- Create new customer-level features
- Perform exploratory data analysis
- Generate business-oriented insights

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Structure

- `customer_data_cleaning_and_analysis.ipynb` — Main data cleaning and analysis notebook
- `README.md` — Project documentation

## How to Run

The notebook is designed to run in Google Colab.

Download the notebook and open it in Google Colab, then run the cells from top to bottom.

## Main Analysis

The project includes:

- Dataset overview
- Missing value analysis
- Duplicate detection
- Data type cleaning
- Invalid age detection
- Missing value handling
- Logical consistency checks
- Spending consistency analysis
- IQR-based outlier detection
- Feature engineering
- Customer segmentation
- Business insights
- Data visualization
- Correlation analysis
- Final data quality report
